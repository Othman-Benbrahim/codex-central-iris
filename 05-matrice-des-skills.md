# 05 — Matrice des skills

Ce document aide à orienter l'usage des skills sans créer d'orchestration rigide.

## Tableau d'orientation

| Besoin utilisateur | Skill principal recommandé | Complément éventuel |
|--------------------|----------------------------|---------------------|
| Tirage symbolique, lecture d'archétypes | `Fractales-du-destin` | `STELE` |
| Compression symbolique d'une situation | `STELE` | `Fractales-du-destin` |
| Clarification de blocages personnels | `Miroir-des-paradigmes` | `Hacking Narratif` |
| Réécriture d'un récit | `Hacking Narratif` | `Miroir-des-paradigmes` |
| Signaux faibles et prospective | `Signaux-du-futur` | `superforecasting-protocol` |
| Révision probabiliste d'une hypothèse | `bayesian-updater` | `calibration-engine` |
| Audit des prédictions passées | `calibration-engine` | `bayesian-updater` |
| Orchestration des outils de prévision | `prediction-engine` | `superforecasting-protocol` |

## Règle de sélection

Choisir le skill le plus proche du **type d'opération demandé**, pas celui dont l'univers paraît le plus séduisant.

## Règle d'escalade

Ne combiner plusieurs skills que si :

- la demande le nécessite,
- les statuts épistémiques restent clairs,
- la sortie finale reste intelligible.
