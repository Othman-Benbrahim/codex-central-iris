# 02 — Statuts épistémiques

Ce document propose un lexique commun pour qualifier le statut d'une sortie, d'une interprétation ou d'un indice.

## Finalité

L'objectif est d'éviter les glissements entre image, ressenti, hypothèse, indice et conclusion.

## Échelle commune

| Statut | Définition | Usage |
|--------|------------|-------|
| `Image poétique` | Formulation symbolique ouvrant une lecture sans prétention de preuve | Skills symboliques |
| `Résonance subjective` | Impression vécue, significative pour l'utilisateur, non vérifiée | Symbolique, introspectif |
| `Hypothèse intuitive` | Piste de sens plausible, encore non testée | Symbolique, narratif |
| `Hypothèse analytique` | Proposition explicative structurée susceptible d'être révisée | Analytique |
| `Signal faible observable` | Indice discret descriptible, encore insuffisant pour conclure | Prospectif, OSINT |
| `Indice vérifié` | Élément corroboré par une observation, une trace ou une répétition confirmée | Analytique |
| `Conclusion provisoire` | Synthèse prudente, révisable, contextualisée | Tous |
| `Statut spéculatif` | Sortie assumée comme exploratoire, performative ou non factuelle | Symbolique, génératif |
| `Statut performatif` | Sortie visant une transformation subjective ou narrative, non une preuve | Symbolique |
| `Statut descriptif` | Sortie visant à décrire un état ou une structure sans en prédire l'évolution | Tous |

## Règle d'usage

Tout skill devrait expliciter, lorsque pertinent :

- ce qu'il **ouvre**,
- ce qu'il **suggère**,
- ce qu'il **observe**,
- ce qu'il **ne peut pas prouver**.

## Interdiction de glissement

Il est interdit de :

- présenter une image poétique comme un fait,
- présenter une intuition comme une preuve,
- présenter un signal faible comme une certitude,
- présenter une conclusion provisoire comme définitive.
