# 00 — Carte de l'écosystème

Ce document présente la structure d'ensemble de l'écosystème IRIS∞ et la fonction générale de ses familles de skills.

## Finalité

L'écosystème IRIS∞ articule plusieurs régimes de traitement :

- symbolique,
- narratif,
- introspectif,
- analytique,
- probabiliste,
- méta-calibratif.

L'objectif du Codex n'est pas de fusionner ces régimes, mais de les rendre **interopérables sans confusion**.

## Grandes familles

### 1. Skills symboliques

Ces skills travaillent les motifs, les archétypes, les résonances et les transcriptions symboliques.

Exemples :
- `Fractales-du-destin`
- `STELE`
- `TCAI-transcommunication-algorithmique-intelligente`
- `Metalangage-des-resonnances`

### 2. Skills narratifs et introspectifs

Ces skills accompagnent la mise en récit, la clarification intérieure, l'exploration de paradigmes ou la transformation symbolique du récit.

Exemples :
- `Miroir-des-paradigmes`
- `Hacking-Narratif-Agent-Hybride-de-Transformation-Symbolique`
- `oracle-synchromantique-des-recits-IRIS-`

### 3. Skills analytiques et prospectifs

Ces skills traitent les hypothèses, les signaux, les scénarios et les révisions probabilistes.

Exemples :
- `Signaux-du-futur`
- `superforecasting-protocol`
- `bayesian-updater`
- `prediction-engine`
- `calibration-engine`

## Principe de séparation

Chaque famille répond à une logique différente. Le Codex impose donc une règle simple :

- ne pas faire passer une sortie symbolique pour un fait,
- ne pas faire passer une hypothèse analytique pour une certitude,
- ne pas faire passer une introspection pour un diagnostic,
- ne pas faire passer une modélisation probabiliste pour une vérité définitive.

## Fonction du Codex

Le Codex Central existe pour maintenir la lisibilité entre ces familles :

- langage commun,
- limites communes,
- formats communs,
- orientation commune.
