# 07 — Roadmap du Codex

Ce document suit les évolutions prévues du Codex Central IRIS∞.

## Priorités initiales

### Phase 1 — Stabilisation documentaire

- fixer la nomenclature,
- harmoniser les statuts épistémiques,
- harmoniser les garde-fous,
- stabiliser les formats de journaux,
- documenter la carte de l'écosystème.

### Phase 2 — Alignement des skills existants

- relire les SKILL.md existants,
- identifier les duplications,
- migrer certains éléments transversaux vers le Codex,
- conserver l'autonomie des protocoles métier.

### Phase 3 — Préparation d'un agent de simplification

- observer les points de friction réels,
- identifier ce qui doit être simplifié,
- distinguer simplification de l'accès, de la sortie et de la structure,
- éviter de créer une dépendance prématurée.

## Gouvernance recommandée

Toute modification du Codex devrait vérifier :

1. est-ce vraiment transversal ?
2. est-ce stable dans le temps ?
3. cela évite-t-il une duplication réelle ?
4. cela respecte-t-il l'autonomie des skills ?

## Critère de réussite

Le Codex réussit s'il rend l'écosystème :

- plus lisible,
- plus cohérent,
- plus traçable,
- plus maintenable,
- sans le rendre plus rigide.
